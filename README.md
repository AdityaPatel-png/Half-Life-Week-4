# Half-Life-Week-4
This project will be a projector that works similar to an external monitor.
In that, I mean that it will connect using an hdmi/display port cable and it will be compatible with most computer devices.
It will use a pcb with some lense shenanigans for the projectering and I'll make a big space for a cooling system in the case.
Main resources used: KiCad and Fusion360
